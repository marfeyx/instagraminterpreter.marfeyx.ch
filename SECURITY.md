# Security Policy

## Reporting a vulnerability

Report security issues through the repository's
[private vulnerability reporting form](https://github.com/marfeyx/instagraminterpreter.marfeyx.ch/security/advisories/new).

Do not attach Instagram exports, message contents, access credentials, or other personal data to a public issue.
If private vulnerability reporting is unavailable, open a public issue containing only a request for a private contact
channel and no vulnerability details.

## Supported version

Only the latest version on the `main` branch is supported.

## Data handling

The application is designed to process Instagram export ZIP files locally in the browser. Security reports should flag
any behavior that transmits or persists imported content without a clear, documented user action.
